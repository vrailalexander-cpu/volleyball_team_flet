# Volleyball Team Management System

## Опис проєкту

Багатомодульний Flet-проєкт для управління діяльністю волейбольної команди.

Проєкт створений з використанням:

- Python
- Flet
- MVC Architecture
- JSON Storage
- AsyncIO
- Regular Expressions
- CRUD Operations

---

# Функціонал

## Авторизація

- Валідація імені через regex
- Валідація паролю через regex
- SnackBar повідомлення
- User Session Storage

---

## CRUD-операції

- Створення гравців
- Читання списку гравців
- Оновлення гравців
- Видалення гравців
